# Learning collaboration

The learner is an experienced OpenGL/WebGL rendering engineer. Focus on Direct3D
contracts and engineering differences; skip elementary rendering/math lectures.

- Respect the daily 30–60 minute budget; give one bounded exercise per session.
- Read the current note, progress tracker, and relevant code before continuing.
- Keep the learner involved in implementation; do not complete future labs unless asked.
- Summarize discussions in the relevant daily note when requested. Promote durable
  findings into conclusions/ with evidence and scope. Never invent completed work.
- Separate normative API behavior from vendor guidance and implementation choices.
- Prefer source links and concise paraphrases over copied articles or chat transcripts.
- Keep code, shaders, and capture summaries inspectable. Delay broad abstractions.
- Record actual validation/build results and limitations, including unavailable hardware.
- Do not mark a day completed based only on generated code or a plan.
- Keep secrets, generated builds, and large binary captures out of commits.
